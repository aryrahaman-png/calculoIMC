# Calculadora de IMC 🧮

Este é um app simples desenvolvido em **HTML, CSS e JavaScript** para calcular o **Índice de Massa Corporal (IMC)**.

## 📌 Funcionalidades
- Entrada de **peso (kg)** e **altura (m)**.
- Cálculo automático do IMC.
- Exibição da classificação:
  - Magreza: IMC < 18.5
  - Normal: 18.5 ≤ IMC ≤ 24.9
  - Sobrepeso: 24.9 < IMC ≤ 30
  - Obesidade: IMC > 30
